Lead UX / UI designer - Responsive web

// Project aim

The primary objective was to move the existing HL website over to AEM (Adobe Experience Manager) and improve the customer experience where possible.


A substantial research piece was carried out to gather the data we needed to understand the help section. Some of the data points we researched were; Call centre agents, Call centre transcripts, emails, web analytics, product owners and end user interviews.


The initial stages were to look into the help section and start to migrate components, templates and patterns over to the new framework. The new UI library formed off the back of this would then feed into a new Design system.


The key KPI on this project was to reduce the call centre volumes caused by the pandemic and allow users to self serve rather than call.


Tools used; Sketch, Invision, DSM, UXPin, MIRO, Figma, Optimal sort.

// Foundations

In this stage we looked at the granular level of the design system. We wanted a set of building blocks and rules that would give us the consistency and flexibility to build out any scenario HL wanted to design across all of their digital products.

// Grid & Template

The existing grid was 12 column and had no rules on baseline and vertical rhythm. This was causing the layouts to be very random and visual hierarchy got lost across different sections in the site and app.


We found through user testing that this simple design fault was an issue and users felt it slightly unsettling especially when dealing with large sums of money.We looked at a 16 col grid (16, 8, 4, 2, 1 column layouts) , golden ration for typography and spacing and layout spacing, coupled with a 4px baseline this gave us the bed we needed.

// User testing

Before user testing we held a few ideation sessions to filter out what design we had confidence in and refined these for testing in front of end users. Sketching is my preferred method in these sessions as its quick and gets the concept across before fleshing out hi fidelity versions.


Once designed I transferred the pages into UXPin ready for user testing with Joe. Test scripts were then written off the back of the prototype to whittle down the most efficient design and patterns


These sessions were fully remote and we were able to invite wider team members into the testing so they can see how valuable these interviews are.

// Build components and document

We built the initial design files in sketch, but half way through we got the green light we could use Figma so a small amount of migrating was needed to complete this but the processes remained the same for building components.


The new UI library can be consumed by all the UX, UI and wider creative teams. This is proving a huge success in streamlining the time designers used to spend on remaking buttons, form fields etc, allowing them to focus on the experience and small touches that bring the brand to life.
